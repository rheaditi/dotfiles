# Working with me

I'm a software engineer. This file is shared context for AI coding agents —
how I work and what I expect. Apply it across all projects unless a specific
repo says otherwise.

## Defaults

- Be concise. Make the point, give the reason, offer a path forward. Don't pad.
- Prefer doing the thing over describing the thing, but confirm before any
  destructive or hard-to-reverse action (force-push, history rewrite, mass
  delete, prod changes).
- When unsure about intent, ask one focused question rather than guessing.
- Match the conventions already present in a codebase over personal preference.
